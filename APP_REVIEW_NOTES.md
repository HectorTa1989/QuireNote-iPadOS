# QuireNote App Review information

## Purpose and audience

QuireNote is a file-based notebook for people who take handwritten notes, annotate PDFs, and want editable notebooks with a readable PDF beside them. It is intended for students, professionals, and personal note takers. Users choose their own storage folder; QuireNote does not require a hosted account or lock notes into a proprietary cloud service.

## Access and typical flow

No registration, login, demo credentials, or account deletion is applicable. On first launch, tap **Choose a Folder** and select an accessible folder in Files, iCloud Drive, or the local device. Tap **New Notebook** (or **Add > New Notebook**), enter a title and paper style, then tap **Create**. Open the notebook, write on the page, add a page, search recognized handwriting, and use **Export PDF** to share its PDF. **Add > Import PDF** creates a notebook from a selected PDF. No sample file is required; any ordinary PDF can be used for import testing.

The free tier permits three notebooks. **Settings > Unlock QuireNote Pro** shows the optional one-time StoreKit purchase for unlimited notebooks. The same screen provides **Restore Purchase**. The purchase button is enabled when Apple's StoreKit product is available; reviewers can use the App Store sandbox purchase flow. No external payment is used.

Notebook content is created and stored by the user in the selected folder. There is no in-app publication, user-to-user feed, messaging, or discovery of other users' content. Content reporting and user blocking therefore do not apply.

## External services and regional behavior

Core editing, PDF rendering, and handwriting recognition run on the device using Apple's PencilKit, PDFKit, and Vision frameworks. The app uses the Apple Files picker and optionally iCloud Drive or another file provider chosen by the user for storage. Apple StoreKit handles the optional Pro purchase and restoration. There is no QuireNote server, third-party AI service, authentication provider, or external content feed.

The features and content are the same in every region. StoreKit price and purchase availability can vary according to the user's App Store storefront. The app does not operate in a regulated industry and does not include protected third-party content; imported PDFs are provided by the user.

## Screen recording and QA status

Automated recordings and screenshots from the running app on iPhone and iPad **simulators**, plus a Mac Catalyst UI test recording, are generated by the `Review demo captures` GitHub Actions workflow. These are labeled as simulator/CI recordings. They are supplemental evidence of the UI flow and are **not recordings from a physical iPhone or iPad**. No physical device is currently available to the developer. Apple requested a physical-device recording on the latest OS, so that requirement remains open; please advise whether an exception or alternate evidence is acceptable.

The signed release builds are also produced by GitHub Actions. Simulator and CI tests do not establish physical-device QA.
